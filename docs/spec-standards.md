# Padrões de specs

- Local: `specs/XXX-nome-da-spec/`.
- Use exclusivamente `specs/_template/` como modelo e preserve sua estrutura,
  seções, ordem e formatação.
- Leia somente o template e os arquivos da spec solicitada. Não examine outras
  specs salvo quando a tarefa exigir comparação ou contexto histórico.
- Ao criar uma nova spec, crie inicialmente apenas o `spec.md`; gere `plan.md`
  e `tasks.md` apenas quando o planejamento ou a execução forem solicitados.
- Mantenha `spec.md`, `plan.md` e `tasks.md`; crie `review.md` apenas quando
  houver revisão a registrar.
