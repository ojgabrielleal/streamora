# Spec 005 - Criação das primeiras repositories

**Status:** Concluída
**Branch:** feature/005-criando-primeiras-repositories

## Objetivo
Criar as primeiras repositories do projeto

## Requisitos
- Criar as repositories na pasta `src/main/java/com/streamora/streamora/repository`
- Todas as repositories devem ter um "acessor" pra busca por `uuid`
- Os nomes de cada arquivo de repository deve seguir a convenção já existente na comunidade
- Todas as repositories devem ser baseadas nas entities já criadas em `src/main/java/com/streamora/streamora/entity`

## Critérios de aceite
- [x] Todas as repositories devem ser baseadas nas entities já criadas em `src/main/java/com/streamora/streamora/entity`
