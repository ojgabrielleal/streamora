# Spec 006 - Criação dos primeiros services

**Status:** Concluída
**Branch:** feature/006-criando-os-primeiros-services

## Objetivo
Criar dos primeiros services do projeto

## Requisitos
- Criar os services devem estar na pasta `src/main/java/com/streamora/streamora/service`
- Todas os services devem ter métodos para cada operação de CRUD `index`, `show`, `store`, `update`, `delete`
- O service responsável pelo `file` deve ter métodos para adicionar e remover o arquivo `file` de uma playlist.
- Os nomes de cada arquivo de service deve seguir a convenção já existente na comunidade
- Todas os services devem ser baseadas nos repositories já criados em `src/main/java/com/streamora/streamora/repository`
- Atualizar o docs de estrutura do site já existente

## Critérios de aceite
- [x] Todas os services devem ter métodos para cada operação de CRUD `index`, `show`, `store`, `update`, `delete`
